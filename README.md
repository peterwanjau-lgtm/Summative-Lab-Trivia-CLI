CLI Trivia Game

A simple command-line trivia game built with Node.js.

How to Run

Make sure you have Node.js installed.

Save the code as index.js.

Open your terminal and run:

node index.js


How to Play

Type yes to start.

Answer each question by typing A, B, C, or D.

You have 10 seconds per question.

See your final score at the end!
